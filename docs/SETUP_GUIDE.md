# Setup Guide — AI Fitness App

## Prerequisites

| Tool | Version | Install |
|---|---|---|
| Flutter SDK | ≥ 3.3.0 | [flutter.dev](https://flutter.dev/docs/get-started/install) |
| Dart SDK | ≥ 3.3.0 | Included with Flutter |
| Android Studio | Latest | [developer.android.com](https://developer.android.com/studio) |
| Xcode (iOS only) | ≥ 15 | Mac App Store |
| Firebase CLI | Latest | `npm install -g firebase-tools` |

## Step 3 — Firebase Setup

### 3.1 Create Firebase Project

1. Go to [console.firebase.google.com](https://console.firebase.google.com)
2. Click **Add project**
3. Name it (e.g. `ai-fitness-app`)
4. Disable Google Analytics (optional)
5. Click **Create project**

### 3.2 Enable Firebase Services

#### Authentication
- Firebase Console → **Authentication** → **Get started**
- Enable **Email/Password**
- Enable **Google** (requires SHA-1 fingerprint for Android)

#### Firestore Database
- Firebase Console → **Firestore Database** → **Create database**
- Select **Start in test mode**
- Choose your region
- Click **Create**

#### Firebase AI Logic
- Firebase Console → **AI Logic** → **Get started**
- Select **Gemini Developer API**
- Follow the setup wizard

### 3.3 Configure FlutterFire

```bash
firebase login
flutterfire configure
```

- Select your Firebase project
- Select platforms: **android, ios**
- Android package: `com.sujeet.ai_fitness_app`
- iOS bundle: `com.sujeet.aiFitnessApp`

This generates:
- `lib/firebase_options.dart`
- `android/app/google-services.json`
- `ios/Runner/GoogleService-Info.plist`

### 3.4 Add SHA Fingerprints (Google Sign-In)

Get your debug SHA-1 and SHA-256:

```bash
keytool -list -v \
  -keystore ~/.android/debug.keystore \
  -alias androiddebugkey \
  -storepass android -keypass android
```

Add both fingerprints in:
Firebase Console → Project Settings → Your apps → Android app → **Add fingerprint**

## Step 7 — Firestore Security Rules

In Firebase Console → Firestore → **Rules**, apply production rules:

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId} {
      allow read, write: if request.auth != null
                         && request.auth.uid == userId;
      match /{subcollection}/{docId} {
        allow read, write: if request.auth != null
                           && request.auth.uid == userId;
      }
    }
  }
}
```

## Troubleshooting

| Issue | Fix |
|---|---|
| `HiveError: Box not found` | Make sure `Hive.openBox()` is called in `main()` |
| `Splash screen stuck` | Check Firebase initialization and `prefsServiceProvider` |
| `AI coach not responding` | Enable Firebase AI Logic in Firebase Console |
| `Google Sign-In fails` | Add SHA-1 fingerprint to Firebase project |
| `minSdkVersion error` | Set `minSdk = 23` in `android/app/build.gradle.kts` |
| `google-services.json missing` | Re-run `flutterfire configure` |
| Gradle build slow | First build downloads dependencies — subsequent builds are faster |
